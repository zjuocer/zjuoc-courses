## 个人评价

### 2025-2026 春夏

课程由信息学与阵列信号处理两部分组成。成绩构成中包含作业和实验、考试、期中期末等环节。

信息学部分的考试内容和作业、历年卷内容重合度较高，面向这些资料复习即可，整体难度不算太高；课程未点名。

阵列信号处理部分的考试内容会随学期略有调整。本学期没有检测和估计方面的内容，多了模糊度函数和雷达探测相关内容。考试主要考察直接背诵与应用背诵的内容。从历年卷来看，阵列方向图、主瓣、旁瓣、最小化输出信号方差以及噪声方差的两个优化方程是重点内容。

整体来看课程比较轻松，期中和期末内容分开准备即可。考试范围相对明确，主要来自历年卷和作业中出现的问题，平时把推导过程记清楚即可。

如果后续想做信息方向，这门课可以作为基础课继续深入。可按个人需要参考 Kay 的 Fundamentals of Statistical Signal Processing Vol. 1 / Vol. 2，或王永良老师的空间谱估计理论与算法，以及 Array Signal Processing Concepts and Techniques、Optimum Array Processing 等资料。如果只是完成课程，认真完成作业和历年卷已经足够取得较满意的成绩。
